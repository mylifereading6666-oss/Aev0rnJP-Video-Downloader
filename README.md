# Aev0rnJP Video Downloader

スマートフォン・PCのブラウザで使える無料の動画URL確認ツールです。

**公開URL:** https://mylifereading6666-oss.github.io/Aev0rnJP-Video-Downloader/

## 現在の機能

- スマートフォン・PC向けレスポンシブUI
- 初回利用時の注意事項確認
- HTTP/HTTPS URLの形式チェック
- 直接動画ファイルURLのプレビュー（配信元が許可している場合）
- 取得可能な場合に、動画の解像度・再生時間・ファイルサイズ・Content-Typeを表示
- URLのファイル名をタイトル候補として表示
- 動画URLを開く・コピーする・ブラウザのダウンロードを試す
- GitHub ActionsによるGitHub Pagesへの自動デプロイ

## 重要な制限

このサイトは GitHub Pages の静的サイトです。バックエンドサーバーや動画サイトのAPIは使用していません。

- URLの形式チェックは、動画が実際にダウンロードできることを保証しません。
- タイトルはURL内のファイル名から推定します。動画ページの正式タイトルや公式サムネイルを取得する機能はありません。プレビューは動画ファイルを再生できる場合に表示されます。
- ファイルサイズは配信元が情報を公開し、ブラウザから取得できる場合のみ表示されます。
- CORS、認証、Referer制限、配信元の設定、ブラウザや端末の仕様によっては、プレビューやメタデータを取得できません。
- 別ドメインのファイルでは、ブラウザが `download` 指定を無視し、再生・表示だけになる場合があります。
- 画質変換、複数画質の選択、HLS/DASHの解析・結合は行いません。
- YouTubeやSNSの動画ページから動画を抽出したり、DRMやアクセス制限を回避したりする機能はありません。

ダウンロードする権利があるコンテンツだけを扱い、著作権法と各サービスの利用規約を守ってください。保存できない場合は配信元の公式ダウンロード機能を利用してください。

## 公開・デプロイ

GitHub Actions ワークフロー `.github/workflows/pages.yml` が `main` ブランチへの push 時に自動デプロイします。

1. GitHub リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **GitHub Actions** に設定する。
3. **Actions** タブで「Deploy website to GitHub Pages」の実行が成功したことを確認する。
4. 公開URLをスマートフォンとPCで確認する。

## 公開前テスト

詳細なチェックリストは [TESTING.md](./TESTING.md) を参照してください。コード上の要素確認と、実際の動画URLを使った再生・ダウンロードテストは別です。実際の保存動作は、端末・ブラウザ・配信元ごとに確認する必要があります。

## プライバシー

入力したURLをこのサイト独自のバックエンドに送信・保存する処理はありません。URL確認時には、ブラウザから指定された動画配信元にアクセスします。配信元は通常のアクセスログを取得する場合があります。
